# Cognifyz Task 4 - Interactive Button

## About the Project
This project is part of my Front-End Development Internship at Cognifyz Technologies.

## Objective
To use JavaScript to make a webpage interactive by changing its background color when a button is clicked.

## Features
- Interactive background color changer
- Multiple background colors
- Responsive and centered layout
- Button hover effect
- Dynamic message after clicking

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
Open `index.html` in a web browser and click the Change Background button.

## Learning Outcome
I learned how to use JavaScript event listeners and DOM manipulation to update webpage styles dynamically.
